# Инструменты tools/

Таблица «что проверяет каждый прогон». Вынесена из CLAUDE.md: нужна только тому, кто запускает тест.
Запуск в тихом режиме (только провалы и итог): `node tools/q.js <тест>.js`.

| `src-parts.js` | Исходник разрезанного модуля целиком (файл + продолжения по порядку `index.html`) — для калькуляторов, которые eval'ят код без браузера |
