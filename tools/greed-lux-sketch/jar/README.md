# Банка-кошелёк: 3D-болванка

`jar.obj` — «Glass Jar» by Jarlan Perez (Poly Pizza, CC-BY; прислан игроком
10.11.2026). Детали: mat25 — стекло снаружи, mat24 — стекло изнутри
(толщина стенок), mat15 — крышка отдельно. Болванка для места, подлёта и
раскладки экрана прокачки (план 31, разд. 00); в игру уходит перерисовка.

* `jar.html` — съёмка: `?yaw&pitch&lid` (подъём крышки), `&coins=N` —
  куча монет внутри, прозрачный фон.
* `jar-board.py` — раскадровка подлёта на кадре игры.
