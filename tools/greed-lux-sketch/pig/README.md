# Свинья-копилка: 3D-болванка

`piggy.obj` — «Piggy bank» by Poly by Google, лицензия CC-BY 3.0
(архив Google Poly; прислан игроком 10.11.2026). Модель — болванка для
положения, ракурса и подлёта копилки (план 31, разд. 00); в игру уходит
перерисованная 2D-версия, не модель.

* `pig.html` — просмотр и съёмка: `?yaw=..&pitch=..&roll=..` (градусы),
  прозрачный фон. Открывать через `python3 -m http.server 8777` из корня.
* `pig-shot.js` — снимки ракурсов и раскладка в кадр игры.
