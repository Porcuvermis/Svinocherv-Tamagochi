# Ревизия света и рельефа

Порядок и словарь симптомов — `docs/bench/greed-audit.md` (разд. 3–4, 8).
Главное оттуда: деталь смотрят во ВСЕХ состояниях (покой, касание, наклоны)
и сравнивают со старой версией разностью, а не одним кадром крупным планом.

## Инструменты

| Сцена | Вдавленное (канава по контуру) | Свет по частям |
|---|---|---|
| Гримёрка тщеславия | `tools/pride-room-audit.js` (всё в одном) | там же, кадры `b-*`, `c-off-*`, `a-*` |
| Аппарат алчности | `tools/greed-sink.js` | `tools/greed-part.js` (`PART=…`) |
| Новая сцена на `Lit.kit` | скопировать `pride-room-audit.js`, заменить `PRIDE_ROOM` своей сценой | — |

```bash
python3 -m http.server 8777    # из корня, если не поднят
NODE_PATH=/opt/node22/lib/node_modules node tools/pride-room-audit.js /tmp/pra-
python3 tools/sheet.py /tmp/pra-f- 5 260     # лист кадров — смотреть его
```
`REGION=x,y,w,h` — только участок; `FRAMES=0` — без кадров.

## Порядок

1. **Воспроизвести то, что видит игрок** (состояние, наклон).
2. **Вдавленное.** Список мест с деталью сверху (`T(h, материал)` + начало
   разметки — по нему ищется код). Чинить ВЫСОТЫ, не свет: порядок
   заливка→профиль, стопка, `hollow`, грозди (скилл `lit-scene`, п. 3–6).
   Нарочно утопленное — `sunk`, дыры — `pit` (инструмент их не считает).
3. **Потолок/дно размаха** — круглое плоское сверху: поднять `HMAX`/опустить
   высоты.
4. **Свет по частям:** `normal, shade, lit, lamps, spec, depth, ao, height,
   plane`; выключение по одному `off=key,lamps,ao,floor,mirror,shadow`.
   Пропало при выключении — виноват он. Не пропало ни при одном — рельеф
   или рисунок (карты).
5. **Одна причина — одна правка**, проверенная выключением. Общая правка
   шейдера — разность ВСЕГО кадра.
6. Снова инструмент: места ушли, остальное не изменилось.

## Отчёт игроку (всегда три части)

* **Сделано и видно** — сколько было мест → сколько осталось, что за
  причины, снимок до/после в тех же состояниях.
* **Не сделано / не уверен** — что оставлено и почему; на телефоне сам не
  смотрел — так и написать.
* **Почему было так** — одна-две фразы.
Урок, стоивший переписывания, — в `docs/traps.md` с оглавлением.
