# Выкатка в бота

Игрок смотрит игру только на iPhone в Telegram-боте. Пуш в любую ветку →
GitHub Actions → Pages; бот открывает ветку с самым свежим коммитом
(`docs/deploy-iphone.md`). Мержить в main не нужно.

## Порядок

1. **Проверка** — скилл `verify` (снимки, тесты своего греха,
   `test-no-words.js`). Провал — не выкатывать молча.
2. **Документы — только то, что изменилось по смыслу:**
   * `docs/plan/00-done.md` — строка греха / ядра («сделано» = играется);
   * план греха `docs/plan/NN-*.md` — решения игрока и «почему так»;
   * новые файлы — `docs/structure.md`; новый прогон — `tools/README.md`;
   * новая область задач — строка в маршрутизаторе `CLAUDE.md`;
   * ошибка повторилась второй раз или стоила переписывания —
     `docs/traps.md` (раздел в конце + строка в ОГЛАВЛЕНИИ, иначе не найдут);
   * `docs/progress-log.md` НЕ открывать; запись туда — только если
     поменялось правило (дописать в конец, не читая).
3. **Коммит** по-русски: первая строка — «Грех: что видно игроку», ниже
   пара абзацев «что и почему». В конце — строки авторства из системного
   напоминания сессии. Модель в тексте коммита не упоминать.
4. **Пуш** в рабочую ветку сессии: `git push -u origin <ветка>`, при сетевой
   ошибке — до 4 повторов с паузой. Отклонён (на ветке чужие коммиты) —
   `git fetch origin <ветка> && git merge --no-edit FETCH_HEAD`, без
   force-push. PR не создавать без просьбы.
5. **Отчёт игроку** — коротко, по-русски, без воды (его предпочтение):
   * что изменилось на экране (можно лист снимков через SendUserFile);
   * «открой в боте, Reload Page» (не «иконкой»);
   * честно: что не проверено (на телефоне сам не смотрел), что осталось;
   * что именно посмотреть в боте.
