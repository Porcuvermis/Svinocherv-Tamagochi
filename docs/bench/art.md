# Верстак: картинка

Новый предмет, фон, еда, мебель. Как рисовать, чтобы это встало в игру, а не
рядом с ней.

---

## 1. Крепёж: цвет и линия берутся, а не придумываются

Цвет — только из `PALETTE`, толщина — только из `STROKE`. Хардкод
`#rrggbb` запрещён.

Иерархия линий жёсткая:

| | |
|---|---|
| `contour` 2.6 | ВНЕШНИЙ силуэт фигуры — самая толстая линия в кадре |
| `structure` 1.7 | границы крупных частей внутри силуэта |
| `detail` 1.0 | складки, борозды, сосуды |
| `hairline` 0.6 | микродетали |

**Ничто внутри силуэта не имеет права сравняться с контуром** ни по толщине,
ни по тону — иначе деталь спорит с силуэтом и фигура рассыпается. Внутренние
черты берут не `INK`, а осветлённый от него тон (`inkSoft`).

---

## 2. Размерность: перспектива одна на кадр

У сцены один горизонт. Соседние плоскости уходят вглубь одинаково. Предмет,
нарисованный «примерно в перспективе», виден сразу — и ломает весь кадр, а
не только себя.

Твёрдые предметы не рисуются от руки, а **запекаются из 3д**: модель в
`tools/`, на выходе SVG с якорями. Гнёзда — не числа, а якоря запекания.

---

## 3. Что обязан сделать автор

1. **Три фигуры — предел** для предмета размером с монету. Четвёртая
   превращает его в кашу: понять, что это, уже нельзя.
2. **Объём даёт не обводка и не тень под предметом, а КРУПНЫЙ мягкий блик.**
   Мягкость — градиентом, а не размытием: фильтр стоит своей площади.
3. **Материал рисуется формой, а не поверх формы.**
4. **Силуэт проверяется на трёх фонах.** Предмет, который читается только на
   своём фоне, не читается.
5. **Светлая деталь обязательна там, где фон может быть тёмным.** Кожа червя
   бывает почти чёрной.
6. Прозрачность назначается детям, а не группе: группа с `opacity` — это
   отдельный буфер.

## 4. Как проверить

```bash
NODE_PATH=/opt/node22/lib/node_modules node tools/check-perspective.js   # сходятся ли грани, один ли горизонт
NODE_PATH=/opt/node22/lib/node_modules node tools/audit-food.js          # продукты: объём, контур, силуэт
NODE_PATH=/opt/node22/lib/node_modules node tools/audit-kitchen.js       # предметы кухни по одному
NODE_PATH=/opt/node22/lib/node_modules node tools/audit-bath.js          # запечённые предметы крупно
NODE_PATH=/opt/node22/lib/node_modules node tools/zoom-kitchen.js        # лупа на кусок сцены
```

**Правку показали картинкой — картинку надо ИЗМЕРИТЬ, а не пересказать.**
Разборы (`audit-*`) снимают предмет крупно, по одному и на трёх фонах —
именно потому, что на общем плане брак не виден.
