# Не решено

Из присланного документа, раздел 13. Здесь же имеет смысл дописывать ответы
по мере того, как они появляются.

* **Выбор стека бэкенда и хостинга.** Рекомендация автора плана: Node.js +
  Fastify + PostgreSQL, деплой на Railway или Fly.io — дёшево, быстро
  поднимается, есть managed Postgres.
* **Ближайшая цель первой недели.** Нужна одна заметная цель, достижимая за
  2–3 дня (первое оружие, первый скин, первый пройденный рогалик). Без неё
  вся экономика будет ощущаться как бесконечное капание.
* **Что происходит при обнулении шкалы.** Сейчас последствий нет. Нужны:
  визуальное состояние червя, возможно штраф, возможно платное «лечение».
  Без этого падающие шкалы ничего не значат.
* **Пул из 20–30 усилений для рогалика.**
* **Конкретные цифры баланса.**
* **Локальные валюты и следы на теле для остальных шести грехов.**
* **Нарративная подача валют** (кристаллы получат тематическое название).
* **Политика push-уведомлений:** пороги, частота, отключение.
