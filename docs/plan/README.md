## Как заводить новый файл

Новый грех или крупная механика — отдельный файл с номером по порядку. В нём
обязательно: **зачем это игроку**, **чем это связано с другими грехами** и
**какие числа за этим стоят**. Строка в таблице выше и строка в
[00-done.md](00-done.md) — тем же коммитом, иначе файл потеряется.
